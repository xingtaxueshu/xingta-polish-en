# 中式英语模式库

格式：**原句 → 改句 → 原因**。例句均为本项目自写，不来自任何已发表文章。改句示范的是语言修正；是否采用取决于作者想表达的内容，改句中的内容不得超出原句。

## A. 冠词与可数性
1. The result are robust to controlling for covariates. → The results are robust to the inclusion of covariates. → 单复数一致；“controlling for + 对象”与主语搭配不当时可改名词化。
2. We use questionnaire to collect data. → We used a questionnaire to collect data. → 可数名词单数需冠词。
3. This is a obvious effect. → This is an obvious effect.（obvious 是否合适另见 H 类）→ a/an 随后词首音。
4. Many researches have shown ... → Many studies have shown ... → research 不可数，常用 studies。
5. He gave me many advices. → He gave me a lot of advice. → advice 不可数。

## B. 时态
6. Last year the author conducted a survey, and the results show that ... → ... conducted a survey, and the results showed that ... → 叙述研究过程用过去时；论文自身的陈述（"Table 3 shows"）可用现在时，同段内要一致。
7. In 1990s, many scholars study this topic. → In the 1990s, many scholars studied this topic. → 过去的时间状语配过去时；the 1990s。
8. The study has been conducted in 2019. → The study was conducted in 2019. → 具体过去时间点不用现在完成时。

## C. 主谓一致
9. The disagreements was discussed. → The disagreements were discussed. → 复数主语。
10. Each of the participants were interviewed. → Each of the participants was interviewed. → each 作主语取单数。
11. The number of studies are increasing. → The number of studies is increasing. → the number of 取单数（a number of 取复数）。
12. Few studies has examined ... → Few studies have examined ... → 复数主语。

## D. 连接词缺失与逗号拼接
13. The sample is small, the results should be interpreted with caution. → The sample is small, so the results should be interpreted with caution. → 两个完整分句需连词或分号；“so”表因果，原句的逻辑关系只能照原意选择。
14. Poetry is hard to translate, however, translators keep trying. → Poetry is hard to translate; however, translators keep trying. → however 作副词不能连接两个分句。
15. Because the data are limited, so we use a simple model. → Because the data are limited, we use a simple model. → because 与 so 不同时用。
16. Although the sample is small, but the effect is large. → Although the sample is small, the effect is large. → although 与 but 不同时用。

## E. 名词堆叠与“的的的”结构
17. the number of the visitors of online exhibition → the number of online-exhibition visitors（或 visitors to online exhibitions） → 连续 of 结构改为前置修饰或介词重组。
18. the influence of the parents' education level on the children's reading ability development → the influence of parents' education on children's reading development → 删去并列冗余名词；是否可删“level/ability”由原意决定，不确定则保留并询问。
19. research on the study of reading habits → research on reading habits → study 与 research 同义重复。

## F. “随着……的发展”类开头与套话
20. With the development of society, more and more scholars pay attention to X. → Increasing scholarly attention has been paid to X. → 删去空泛的“随着社会发展”状语，保留“越来越多”这层意思；该删除记为“可能影响语义（轻微）”，请作者确认；不得补充“已有大量研究”之类新断言。
21. With the rapid development of digital technology, museums play a more and more important role. → Museums are playing an increasingly important role as digital technology develops rapidly. → 同时保留“技术发展”与“作用增强”两个断言，只改句式；二者的因果关联无出处，在问题里提示。
22. It is of great significance to study X. → It is important to study X.（或删掉，直接陈述研究问题） → 空泛重要性套话；“great”不得换成更具体的价值判断。
23. In recent years, ... has aroused wide attention. → In recent years, ... has attracted attention. → “wide”无依据时降为中性；不得补充数据。

## G. 重复与冗余
24. The reason why we do this is because that ... → We do this because ... → 三重冗余。
25. by using NVivo 12 → using NVivo 12 / with NVivo 12 → by using 多余。
26. in the period of the 1850s → in the 1850s → 重复时间标记。
27. at the same time, simultaneously → simultaneously → 同义并列。
28. fill in this gap → fill this gap（或 address this gap） → fill in 用于填表格。

## H. 空泛概括与程度词
29. It can be seen that the family income has an obvious effect on reading time. → Family income has an obvious effect on reading time. → 删去 It can be seen that 和多余的 the；effect 一词是否与研究设计匹配，只提示作者，不自行换成 association。
30. very important → important（或说明重要在哪里：需作者补充） → 程度词冗余，不要擅自换成具体内容。
31. a lot of scholars → many scholars → 正式程度；many 不得升级为 numerous。
32. as we all know → （建议删除，或改为带引用的陈述） → “众所周知”在学术文体里缺乏证据；不替作者补引用。

## I. 介词与搭配
33. be cautious on causal interpretation → be cautious about causal interpretation → 固定搭配 cautious about。
34. different from the perspective of → different in perspective → 视语境；若不确定，询问。
35. take X for example → take X as an example / use X as an example → 固定搭配。
36. pay attention on → pay attention to → 介词。

## J. 话题-评论式结构（汉语语序迁移）
37. As for the method, it is simple. → The method is simple. → 汉语“至于……”式话题句。
38. This phenomenon, we can find it in many cases. → We can find this phenomenon in many cases. → 主题前置后又用代词复指。

## K. 其他常见
39. more and more → increasingly（仅在不改强度时使用） → 书面语。
40. we got 43 codes → we generated 43 codes（或 43 codes were generated） → got 偏口语；generated 是否合适取决于编码流程，不确定则用 identified。

使用说明：本库用于识别模式，不是替换表。每次替换都要回到台账核对数字、引用、术语与论断强度。
