# 人文社科论证文体指引

用途：第三遍（文体与期刊适配）时参考。原则：调整的是**语言的论证标记**，不是论证本身。

## 1. 文献综述（literature review）
- 常见问题：罗列式（A said ... B said ...）、动词单一（say/think/point out 反复）、缺少作者自己的综合句。
- 可做：把同义重复的引述动词换成强度相当的动词；用 `whereas / by contrast / building on` 明确已有的对照关系——**前提是原文已有这层关系**。
- 动词强度对照（同档内替换，不跨档）：
  - 中性陈述：state, note, observe, report
  - 论证/主张：argue, claim, contend, maintain（`claim` 在部分学科略带质疑意味，慎用）
  - 暗示/推测：suggest, propose, hypothesize
  - 证实：show, demonstrate, find（实证）—— 不得把 suggest 升格为 show
- “研究空白”句（gap）：保留原断言的范围与强度。`few studies` ≠ `no studies`；`in China` 的限定不能丢。若无引用支撑，提示作者补充出处，但不要自己添加。

## 2. 理论框架（theoretical framework）
- 区分 `draw on / adopt / build on / extend / critique`：这些词表示与理论的不同关系，不要互换。作者写 `bases on` 通常意在 `draws on` 或 `adopts`——不确定时选语义最窄的 `draws on` 并在清单里写明。
- 概念首次出现给出完整名称，之后保持一致；不要为避免重复而换同义词。
- 理论家姓名与理论名称原样保留。

## 3. 概念界定（definition）
- 常用句式：`X is defined here as ...`、`In this paper, X refers to ...`、`Following Y (year), we understand X as ...`。
- 保持界定的外延：增删限定语等于改界定。`and` 与 `or` 不互换。
- 借用并改动他人定义时，保留“借用+改动”两层信息及引用。

## 4. 论证推进（argument progression）
- 句间标记词只用来**显化已有逻辑**：`first, second`（并列）、`however`（转折）、`therefore`（推论）、`in other words`（换说法）、`for example`。
- 原文逻辑断裂时（前提不足以推出结论、`Thus` 后面没有对应前提）：**不添加连接词来掩盖**，提示作者。
- 总结句 `In a word / In short` → `In sum / Overall`，不要改变总结的范围。
- 避免过度修辞对称（not only ... but also）造成语义偏移。

## 5. 对话式引用（engaging with sources）
- 引用他人观点后的“回应”结构：`X argues that ... However, ...`。保留被引观点与作者回应的边界，不要让引述的断言变成作者自己的断言（或反之）。
- 直接引语：引导语可润色，引语本身不动。引语内的拼写、标点、强调（斜体/省略号）不动；`[sic]` 不自行添加。
- 转述（paraphrase）要保持与原引用相同的强度与范围。
- 书名、文章名的格式（斜体/引号）按目标引文格式，只在不破坏占位标记时调整。

## 6. 时态与人称（人文社科常见习惯，仅作默认，期刊要求优先）
- 引用他人论点：现在时（Barthes argues）或过去时（Barthes argued），同一段内一致。历史学常用过去时。
- 研究方法与步骤：过去时；论文结构说明（Section 3 describes ...）：现在时。
- 第一人称：多数人文社科期刊接受 `I/we`；作者已用 `we` 的保留，不擅自改成被动。

## 7. 方法类/实证类段落（社科）
- 报告统计量时句子框架可调整，数字、符号与显著性水平不动。
- 因果措辞：`increases / effect / impact` 与观察性设计、OLS 相关性不匹配时，只提示，不替作者降级。
- 稳健性、局限性表述（`robust`, `cautious`, `may be overestimated`）保留。

## 8. 禁忌清单
- 不把“有限制的陈述”改写成“有力的陈述”（学术风格不是越有力越好）。
- 不用华丽词替换朴素词（utilize、plethora 之类）。
- 不新增例证、数据、过渡性事实。
