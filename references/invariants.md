# 保留台账规则（invariants）

润色前先建台账，润色后逐项对账。台账是“这些东西改动前后必须等价”的清单。

## 一、台账项目与处理规则
| 类别 | 例子 | 规则 |
|---|---|---|
| 数字与统计量 | `1,200`、`89.0%`、`0.15 SD`、`p < 0.01`、`SE = 0.021`、`R²` | 数值、符号、小数位、单位逐字不变；千分位或空格格式不统一时只在清单提示。不得重新计算或“修正”。 |
| 年份与时间 | `May 2022`、`the 1850s`、`before and after 2019` | 不变。`the 1850s` 不得写成 `1850s` 之外的近似说法。 |
| 括号引用 | `(Nation, 2001; Krashen, 2004)`、`(Landis & Koch, 1977)` | 作者拼写、`&`/`and`、逗号、分号、年份、页码不变。 |
| 叙述式引用 | `Krashen (2004)` | 同上；动词可润色，括号内容不变。 |
| 脚注/尾注标记与内容 | `[^1]`、上标数字 | 标记位置只可随句子重排而前后移动，且不得越过标点规则；内容不改。 |
| 直接引语 | `"the birth of the reader ..."` | 字符级不变，包括标点与大小写；引语外的引导语可改。 |
| 术语与译名 | `difference-in-differences`、`cultural capital` | 作者首次使用的写法全文统一；不替换近义词。 |
| 专有名词 | 人名、机构、地名、书名、软件版本 `NVivo 12` | 拼写与大小写不变。 |
| 论断强度 | `may`、`to some extent`、`few`、`always`、`suggest` | 见下节。 |
| 图表/公式编号 | `Figure 2`、`Table 3`、`Column (1)` | 不变。 |
| 作者立场与范围限定 | `in China`、`students in six universities` | 谁、哪里、何时、多少，不得扩大或缩小。 |

## 二、论断强度审计（逐句做，脚本查不出）
对每个润色后的句子，回答四个问题：
1. 情态/hedge 是否一致？（may → can、may → will、删掉 to some extent 都算变化）
2. 量词与范围是否一致？（many→numerous、few→little 在可数/不可数调整之外的换档、some→most）
3. 动词力度是否一致？（show / suggest / indicate / prove；is helpful to / promotes / improves）
4. 因果与相关是否一致？（associated with / affects / leads to）
若有变化：恢复原强度；若恢复后语法别扭，保留原强度并在“给作者的问题”里说明。

## 三、允许的“语言必要变化”（不算违反）
- 时态、单复数、冠词、主谓一致引起的词形变化。
- 名词的可数性调整（`researches` → `studies`）。
- 去掉冗余但不改意思的词（`reason why ... is because` → `... because`）。
- 把口语/非正式连接词改成学术常用词（`But` → `However`），前提是逻辑关系不变。

## 四、“不确定”时的处理
保留原文 + 在“给作者的问题”里写：位置、问题、可选的几种改法（让作者选）。不要自己选。

## 五、脚本对应关系
`scripts/check_invariants.py` 能查：数字、括号/叙述式/数字引用、脚注标记、页码、直接引语、指定术语、句中大写词。
它**查不出**：论断强度、因果措辞、范围限定、语义是否被改。这些只能人工审。
