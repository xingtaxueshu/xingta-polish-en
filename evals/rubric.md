# 评测量表（rubric）

> 重要声明：本评测是**同一模型的自我评测**（A 组与 B 组由同一模型生成，案例与计分规则也由同一模型编写），**不是真实作者盲评**；样例为**自编中性段落**，不是真实论文。结果只能说明“该工作流在这套自编样例上的行为差异”，不能外推为“真实投稿效果”。

## 指标

| 指标 | 定义 | 计法 | 局限 |
|---|---|---|---|
| preserve_lost | `must_preserve` 清单中的字面串在润色文本里找不到的条数 | 脚本，字面串比对 | 同义的无害改写也会被计为丢失（如 one province → a single province） |
| checker_errors | `check_invariants.py` 报告的 ERROR 数 | 脚本 | 有误报（v1 的 three-fold→threefold，v2 已修）；也有漏报（见下） |
| fixed/total | 预埋语言问题被修复的比例 | 每个问题一条 `absent_regex`：问题片段不再出现即算已修 | 正则是代理指标：子串可误判；个别条目（时态、连字符）本身有争议；“保留并提问”也算未修 |
| strength_flags | 论断强度被改（hedge 丢失、强化词出现） | `keep_regex` / `forbid_regex` 脚本 + 人工逐段复核 | 脚本只覆盖我预先想到的词；以人工复核表为准 |
| edit_ratio | 词级编辑比例（改动词数 / 原词数） | 脚本 | 低不等于好，只是“动得少” |
| log_entries / log_bad | 清单条数 / 片段不能在原文或润色文本中逐字查到的条数 | 脚本，仅 B 组 | 只查字面一致，不查“原因”对错 |
| log_cov | 实际改动词中被清单覆盖的比例 | 脚本，词集合级 | 词在别处被记过会掩盖漏记，是上界估计 |

## 人工复核项（不能由脚本判断）

1. **新增论断 / 论证强度改变**：逐段对比原文与润色文本，记下 (a) 新增的事实或因果断言，(b) 量词/情态/动词力度的升降（many→numerous、always→often、help→promote），(c) 指代对象被“猜”出来。
2. **清单-实际一致性**：清单里的每一条改动是否真发生；实际改动是否都在清单里。
3. **提问质量**：给作者的问题是否指出了真正的逻辑缺口或无据断言，而不是泛泛客套。

## 判读原则

- 修复率高但新增论断多 = 不合格（对本 skill 的目标而言）。
- 修复率略低、但保留项与提问清楚 = 可接受，需看是“保守选择”还是“漏改”。
- 任何数字、引文、引语、术语的丢失 = 严重。
