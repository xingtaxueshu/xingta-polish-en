The concept of digital literacy has been defined by scholars from different perspectives. Some scholars regard it as a set of technical skills, such as operating software and searching for information online. Others think it is a kind of critical ability, which includes evaluating the credibility of online information. In this paper, digital literacy is defined as the ability to find, evaluate, and create information using digital technology. This definition is borrowed from Gilster (1997), but we add the element of "create" to it. We do this because creating content has become an everyday activity of young people.
